# Estudo de README de Perfil — Referência Rafaella Ballerini

> Repositório antigo de estudo utilizado para experimentar a estrutura e os recursos visuais de um README de perfil no GitHub.

## Sobre este repositório

Este repositório preserva um exercício realizado a partir de referências do perfil público de **Rafaella Ballerini**. Ele foi utilizado para estudar elementos comuns em READMEs de perfil, como badges, ícones de tecnologias, estatísticas, links sociais e recursos visuais.

O conteúdo original fazia referência direta ao perfil da criadora. Para evitar que o repositório seja interpretado como autoria ou identidade da proprietária desta conta, esta documentação deixa explícito que se trata de **material de referência/estudo**.

## Conceitos estudados

- Markdown no GitHub;
- HTML embutido em README;
- badges de redes sociais;
- ícones de tecnologias;
- GitHub Readme Stats;
- alinhamento e dimensionamento de imagens;
- links externos;
- personalização visual de perfil.
